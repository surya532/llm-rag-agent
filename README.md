# LLM-Powered Agent with RAG

A Python-based AI agent leveraging Retrieval-Augmented Generation (RAG), dynamic tool calling, and external API integrations to provide context-aware responses grounded in custom knowledge bases.

## Key Features
- **Retrieval-Augmented Generation (RAG):** Context-aware question answering powered by vector storage and semantic search.
- **Tool Calling & API Integration:** Automated workflows using external API integrations and custom agent tools.
- **Modular Architecture:** Clean separation of retrieval, prompt orchestration, and execution logic.

## Tech Stack
- **Language:** Python 3.11+
- **Environment & Package Manager:** `uv`
- **LLM Framework:** LangChain / OpenAI API
- **Vector Database:** ChromaDB
